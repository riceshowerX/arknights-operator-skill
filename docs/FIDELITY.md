# 还原度评估与实测记录

> *博士，我必须诚实地说——我们能做到的，和角色本身之间，还有很长的路。*
> *但每一步，都在让她更接近真实。*

本文记录这个项目「做到了什么程度」，以及「明确做不到什么」。数据来自对特蕾西娅档案的对话测试与量化指标比对，结论适用于大多数角色，但不同角色的数据量差异会带来波动。

---

## 总体判断：约 70–80%

| 维度 | 还原度 | 依据 |
|---|---|---|
| 事实性还原 | ~90% | 种族、阵营、身份、核心事件——PRTS 数据 + `canon_checker` 交叉验证 |
| 表面语言模仿 | ~75–85% | 7 维语言指纹 + 口头禅 n-gram 检测 + 加权情感词典 + Prompt 数据注入 |
| 关系还原 | ~65–75% | 12 种关系类型 + 强度量化（0.0–1.0）+ 跨期演变追踪 |
| 情感深度 | ~50–60% | 上下文感知分类 + 行为链检测 + Mann-Whitney U 显著性检验 + 情感弧线识别 |
| 决策还原 | ~40–50% | 对象差异化分析 + 多信号场景分类 + 风格一致性验证 |

**怎么读这张表**：事实层接近可用的知识库（错误率低但覆盖依赖 Wiki 完整度）；语言层「像」但不算「是」；决策层只是概率性的倾向，不是角色本人的逻辑。

---

## 支撑这些数字的机制

1. **多维语言指纹** — 口头禅/高频短语提取（n-gram），句式长度改用统计分布（四分位 + 变异系数），而非硬阈值。
2. **加权情感词典** — 12 类情感，每词带权重（0.5–1.5），外置为 `tools/_data/emotion_lexicon.json`，可自行扩展。
3. **Mann-Whitney U 统计检验** — 零依赖手写实现，配合 Cohen's d 效应量，替代「看起来差不多」式的粗估。
4. **关系强度量化** — 综合共现频率、情感词密度、直接对话次数，输出 0.0–1.0 强度值与证据条数。
5. **Aho-Corasick 实体识别** — 多模式匹配，角色名库外置并可按需扩展。
6. **ReDoS 防护** — 对正则做安全审计，覆盖 `check_patterns` 与 `exclude_patterns`。
7. **`context.json` Schema 校验** — 版本化 JSON Schema，输出前校验、下游读取时二次校验。
8. **Pipeline 双模式** — `subprocess`（进程隔离，默认）与 `function`（同进程，便于调试）。
9. **语义化版本管理** — 版本号非法时明确报错，而非静默降级。

---

## 局限性（明确做不到的事）

1. **量化 ≠ 理解** — 可以统计省略号出现的频率，但无法理解沉默背后的重量。
2. **关键词匹配的天花板** — 含蓄与反讽表达会失效，暗喻检测只能部分缓解。
3. **矛盾情感缺失** — 「笑着流泪」这类复合情绪，现有词典结构无法表达。
4. **决策逻辑是黑盒** — 「她为什么这样做」只能交给 LLM 推断，脚本给不出因果。
5. **数据覆盖偏差** — 语音文本量通常远大于剧情文本，且语音场景单一（多为对博士说话）。
6. **关系图谱的召回不稳** — 若剧情文本缺少明确的关系表述，`relationship_graph.json` 可能为空图；这属于能力缺口，不是运行失败。

## 后续方向

1. **深层语义** — 从关键词匹配升级到语义嵌入，理解暗喻与言外之意。
2. **对话模拟验证** — 让角色档案生成模拟对话，用它自己反测一致性。
3. **多角色交互** — 双角色对话模拟，检验关系行为是否对称。
4. **把「源石技艺」纳入 Persona Layer 1** — 目前只在 Knowledge 层记录。

## 附：对话测试记录（特蕾西娅）

> 以下为手工测试记录，用于人工评估「像不像」，非自动化用例。

### 场景一：面对追随者的牺牲

```text
用户 > 报告，前线部队全灭...

角色 > ...我知道了。
      将他们的名字记下。每一个人。
      总有一天，我们会建立一个新的家园，
      让他们不必再为我们而战。
      ...他们选择了相信我。这份信任，我会用一生去守护。
```

### 场景二：面对质疑

```text
用户 > 这样做值得吗？牺牲这么多人...

角色 > 你问我值不值得。
      我明白你的疑惑。让我问你一个问题：
      如果不这样，你会怎么做？
      ...
      我不是在质问。我是真的想知道。
      因为有时候，我想找到比牺牲更温柔的路。
```

### 场景三：与阿米娅的对话

```text
用户 > 阿米娅，我有些话想对你说...

角色 > （目光变得更加柔和）
      怎么了，阿米娅？
      你不必像在众人面前那样坚强，
      在我面前，你可以做你自己。
      ...不管发生什么，我都在。
```

### 场景四：对话纠正

```text
用户 > 她不会说"牺牲"，她会说"选择"

角色 > 收到。已写入 Correction #1：
      [场景：被问及个人牺牲] 不应该使用"牺牲"，
      应该使用"选择"——"这不是牺牲，是我选择的路。"
      此规则立即生效。
```

### 场景五：与特雷西斯的对峙

```text
用户 > 特雷西斯就在前方。你打算怎么做？

角色 > ...
      他选择了他的路。而我，选择了我的。
      我不想与他对立——但我不会退让。
      有些事，即使意味着失去，也必须去做。
      ...走吧。不是因为恨，是因为我们必须向前。
```
